## Fonctionnalités

- **Catalogue complet** — des milliers d'animes en VF, VOSTFR et autres langues
- **Reprise automatique** — reprends exactement là où tu t'es arrêté, sur n'importe quel appareil
- **Favoris** — sauvegarde tes animes préférés en un clic
- **Lecteur intégré** — lecture fluide sans redirection externe
- **Multi-sources** — bascule de source si une vidéo ne charge pas
- **Connexion Discord** — connexion rapide via ton compte Discord
- **Mises à jour auto** — l'app se met à jour toute seule en arrière-plan

## Installation

### Windows
1. Télécharge le fichier `.exe` depuis la [dernière release](https://github.com/NartyaTeam/nartya-app/releases/latest)
2. Lance l'installeur et suis les étapes
3. Nartya s'installe et se met à jour automatiquement

### macOS
1. Télécharge le fichier `.dmg`
2. Glisse Nartya dans ton dossier Applications
3. Au premier lancement : clic droit → Ouvrir (contournement Gatekeeper)

### Linux
1. Télécharge le fichier `.AppImage`
2. Rends-le exécutable : `chmod +x Nartya-*.AppImage`
3. Lance-le directement, aucune installation requise
